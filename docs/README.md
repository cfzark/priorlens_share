# Documentation guide

Start with the [Stan-only Lupus posterior](stan_posterior.md). For EPSS, use
[three cases](cases.md) or the [general tutorial](general_tutorial.md).

1. [Install and execute](installation.md).
2. Choose [model names and priors](models.md).
3. Declare [data, targets and grids](configuration.md).
4. Select [method presets](methods/index.md) and their [options](options.md).
5. Choose [posterior computation](posterior.md) and [pseudo-data sampling](sampling.md).
6. Read [outputs and diagnostics](diagnostics.md).
7. Explore [costs](complexity.md), [architecture](architecture.md) and [references](references.md).

The [README](../README.md) provides runnable commands.
